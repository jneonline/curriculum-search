# 온라인 강좌 수강 확인 테스트

최신 반영: 사용자가 다시 제공한 표를 기준으로 2027학년도 1학기 일과후 온공 **37개 과목**을 적용했습니다. `고급 화학`을 추가하고 표 순서 및 교과·유형을 반영했습니다. `소프트웨어와 생활`은 융합 선택 1건입니다. 이전 엑셀의 36개 과목 안내보다 이 수정 목록을 우선합니다. 재반영 스크립트는 상위 폴더의 최종목록 TSV를 사용합니다.

## 2026-11-23 개설과목 갱신

사용자 제공 엑셀의 2027학년도 1학기 일과후 온공 개설과목을 반영했습니다. 원본 37행 중 `소프트웨어와 생활`이 교과 유형을 달리해 두 번 기재되어 있어 조회 목록은 고유 과목 36개로 표시합니다. `data.json`의 `courseDetails`에는 37행의 교과·유형과 원본 셀 위치를 보존합니다. 화면의 개설 학기와 과목 수, 기본 선택도 함께 갱신했습니다.

아래의 22개 테스트 강좌 관련 설명은 이전 자료 수집 범위를 설명하는 기록입니다. 현재 조회 목록은 36개이며, 기존 학교별 전체 과목 검수가 끝나지 않은 자료는 새 과목도 미검색 시 확인 필요로 표시합니다. 원본 사본은 상위 `검토자료/2027학년도_1학기_일과후_온공_개설과목.xlsx`, 재반영 스크립트는 `import_offerings_2027.py`입니다.

2026년 12월 신청 당시 1·2학년을 대상으로 2027학년도 1학기 신청 전 학교의 3개년 편성 과목을 확인합니다.

## 실행과 배포

상위 프로젝트 폴더에서 `powershell -ExecutionPolicy Bypass -File .\start-local.ps1`을 실행하고 http://127.0.0.1:8000 에 접속합니다. 종료는 Ctrl+C입니다. 검증 명령은 `node .\수강확인사이트\check.mjs`입니다. npm 설치나 API 키는 필요하지 않습니다.

`dist` 폴더가 완성된 정적 사이트입니다. Vercel에서는 프레임워크를 Other로 선택하고 빌드 명령 없이 출력 폴더를 `dist`로 지정하면 됩니다. GitHub Pages에서는 `dist` 안의 파일을 Pages 배포 대상으로 사용하면 됩니다. 검색은 브라우저에서 처리하며 별도 서버나 학생 개인정보가 필요하지 않습니다.

## 자료와 결과

- 현재 학년 1학년은 2026 입학생, 2학년은 2025 입학생 자료와 연결됩니다.
- 전남외고·전남미래국제고·송지고는 학과 선택을 요구합니다. 송지고는 보통과·경영정보과를 분리하며 함평골프고는 학과 선택 없이 조회합니다. 한영고는 2025·2026 입학생 공통 편제표를 적용합니다.
- 이름을 NFKC 정규화하고 띄어쓰기를 제거한 후 정확히 일치하는 과목만 비교합니다. 유사한 과목을 자동으로 같은 과목으로 취급하지 않습니다.
- `data.json`의 `courses`를 변경하면 확정 강좌 목록으로 교체할 수 있습니다.
- `schools[].cohorts`는 입학 연도와 선택적 학과를 키로 사용합니다. 예: `2026`, `2025|영어과`.
- `complete: false`인 자료에서 과목을 찾지 못하면 반드시 확인 필요로 표시합니다. 전체 목록 대조를 완료한 자료만 `complete: true`로 바꿔야 합니다.
- 현재 `complete: true`는 광남고의 엑셀 과목 열과 광양여고·중마고·나주고의 해당 편제표 과목 열 추출이 완료된 상태입니다. 학교 담당자의 최신 편제표 승인이나 실제 강좌 운영 자격을 의미하지 않습니다.
- 나머지 학교는 이번 테스트 22개 강좌와 편제표에서 일치하는 과목을 우선 등록했습니다. 모든 과목이 등록되어 있다는 뜻이 아닙니다.
- 편제표가 이미지인 옥과고와 입학 연도별 자료가 부족한 학교는 보완이 필요합니다.
- 사용자 확인에 따라 `2026. 학교교육과정 편성·운영 계획.hwp`는 고흥고등학교, `2026학년도_학교교육과정_편성·운영·평가_계획.hwp`는 광양백운고등학교로 연결했습니다. 고흥고는 2025·2026 입학생의 3개년 표에서 테스트 강좌와 일치하는 과목을 등록했습니다. 광양백운고는 확인한 텍스트에 2026학년도 전학년 표만 있어 입학 연도별 3개년 표의 확인이 필요합니다. 해당 자료를 3개년 교육과정으로 간주하여 판정하지 않습니다.
- 원본 PDF 전체 대신 필요한 입학생별 편제표 페이지만 `dist/sources`에 포함했습니다. HWP/HWPX는 파일명과 해당 표의 제목·과목 주변 내용을 표시합니다.

학생 배포 전 학교별 전체 편제표, 학과별 적용 범위, 편제표 수정 여부와 제한 기준을 대조해야 합니다. 2027 신입생과 현재 3학년은 대상에 포함하지 않습니다.

## 전체 대상과 입학 연도 예외

전체 대상은 103개교입니다. 기본 폴더에서 확인한 교육과정 파일은 106개이며, 파일 수와 학교 수는 구분합니다. 파일 목록은 `검토자료/교육과정_파일목록.json`에 기록했습니다. 현재 사이트에 등록된 학교 수는 별도로 표시합니다. 파일 수집이 전체 과목 대조 완료를 의미하지 않습니다.

조도고등학교의 현재 1학년(2026 입학생)은 2025 입학생의 3개년 편제표로 대체 비교하며 최신 편제표 확인 안내를 표시합니다. 규칙은 `curriculum_policy.json`과 `data.json`의 `cohortOverrides`에 저장했습니다. 솔가람고는 2026 입학생 엑셀 자료를 확보해 대체 규칙을 제거했습니다. 한영고의 동일 교육과정 적용은 `sharedCurriculumYears`에 기록했습니다.
