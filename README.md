# 2027학년도 1학기 온라인 공동교육과정(일과 후) 수강 확인

압축을 풀고 index.html, style.css, app.js, logic.js, data.json, favicon.svg, .nojekyll을 GitHub 저장소의 최상위에 업로드하세요. Pages 배포 대상은 이 파일들이 있는 브랜치의 최상위입니다. 별도 빌드와 서버는 필요하지 않습니다. 검색은 학생의 브라우저에서 처리합니다.

2026년 12월 현재 1학년은 2026 입학생, 현재 2학년은 2025 입학생의 3개년 교육과정과 비교합니다. 택1·택2 등 선택 묶음 과목도 포함합니다. 학교 및 학과를 먼저 선택합니다.

현재 등록 학교는 103개교입니다. 진도고등학교의 2025·2026 입학생 편제표를 추가했습니다. 화순고의 새 PDF, 솔가람고·조도고의 실제 2026 자료, 송지고 학과 분리 및 신설교·학년 부재 예외를 반영했습니다.

전체 검수 완료본으로 표시하지 않습니다. 남은 확인 항목은 반영현황.md에 기록했습니다. 원본에서 학기를 추가 대조해야 하는 일치 과목은 신청 불가로 표시하되 편성 시기 확인 필요를 유지합니다. 자료가 없는 입학연도는 확인 필요로 표시합니다.

현재 강좌는 사용자가 제공한 22개 강좌입니다. data.json의 courses를 바꾸어 확정 강좌를 등록할 수 있습니다. 추가 강좌는 verifiedCourses의 기존 대조 목록에 포함되지 않으면 미편성으로 자동 판정하지 않습니다. 새 과목의 원본 대조를 마친 뒤 입학연도·학과별 verifiedCourses와 records를 함께 갱신하세요.

웹 화면에는 출처만 표시합니다. 원본 링크와 불필요한 추출 상세는 표시하지 않습니다. 성명·학번을 수집하지 않습니다. 원본 파일은 이 ZIP에 포함하지 않습니다.
